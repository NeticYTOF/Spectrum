Spectrum own-terminal runtime (companion folder)
==================================================

This folder contains the OFFICIAL Microsoft Windows Terminal portable
(unpackaged ZIP) distribution, used as the app-owned "Own terminal
(Spectrum only)" runtime. It is NOT installed, NOT registered as the
system default terminal, and reads NO personal terminal settings:
portable mode is enabled by the `.portable` marker file next to
WindowsTerminal.exe, so ALL settings live in this folder's
`settings/` directory (the single Spectrum profile + lockdown
keybindings), per:
https://learn.microsoft.com/en-us/windows/terminal/distributions

The `settings/settings.json` commandline/startingDirectory fields are
REGENERATED by the Spectrum launcher on every "Own terminal" launch
(the launcher computes Spectrum's current absolute path), so the whole
Spectrum package folder can be moved or copied without edits.
